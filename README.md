# Retail Revenue Forecasting & Discount Analytics

An interactive Streamlit dashboard for exploring retail sales and discount patterns using dunnhumby’s *The Complete Journey* dataset. It summarizes weekly net sales and recorded discounts, compares baseline forecasting methods using a holdout backtest, and supports category- and campaign-level exploration.

The project is for learning and portfolio demonstration; findings describe patterns in the provided dataset and should not be interpreted as causal promotion effects.
